# SHANIU 使用指南

> 适用版本：0.2.5（Windows 10 / 11，64 位；0.3.0 尚未发布）。第 0–5 节与 6.1–6.3 描述的能力在本版可用；**§6.4「诊断包」是 0.3.0 才有的能力，本版不可用**（该节已标注）。
> 这份指南写给第一次使用的群友。每一步都按实际界面的文字写。你看到的界面如果和这里不一致，以你屏幕上的为准。

---

## 0. 三分钟上手

1. 在 D 盘建一个固定的文件夹，比如 `D:\SHANIU\`。
2. 把 `SHANIU.exe` 放进这个文件夹，双击运行。（如果你拿到的是压缩包，按 1.2 的压缩包方式放好。）
3. 点界面右下角的「请选择模型」，在「模型」页里给 DeepSeek 填上 API 密钥，点「保存」。保存后卡片下方会自动校验一次，看到「密钥有效」再回主界面。
4. 回到主界面，在输入框里打一句「你好」发送。能收到回复，就说明配置好了。

如果第 4 步失败，先看第 6 节「出问题了怎么办」。

## 1. 安装：放哪里、数据在哪

### 1.1 放在一个固定文件夹里

拿到程序后，**先建一个固定文件夹再放进去**，例如 `D:\SHANIU\`。之后一直用这个位置，不要换。

**不要放在桌面、下载文件夹，也不要用一次挪一次。** 原因很实在：

- 程序的数据（API 密钥、设置、历史会话、默认工作区）存在**程序旁边自动生成的 `data\` 文件夹**里，不在 C 盘的系统目录。
- **只把 `SHANIU.exe` 单独挪走或删掉，`data\` 不会跟着走。** 新位置的程序会当成第一次启动，重新建一个空的 `data\`——看起来就是"我的密钥、设置、会话全没了"。要换位置就整个文件夹一起搬（exe 和 `data\` 一起）。
- 桌面和下载文件夹最容易被清理工具扫掉、被重装系统带走。

同理，不要放在 `C:\Program Files\` 这类需要管理员权限才能写入的系统目录。

**再区分一件事，别把两个概念混在一起：** `data\` 是程序存放自己数据的地方（密钥、设置、会话、日志都在里面）；程序干活用的「工作区」只是它下面的 `data\Workspace` 这**一个子目录**。`data\` 里的其他子目录不是工作区，不要拿它们当项目文件夹；反过来，如果你在界面里另选了一个项目目录，工作区就不在 `data\` 里了。

### 1.2 两种发放形态

群里发的可能是下面两种，用法有区别：

| 你拿到的 | 怎么做 |
| --- | --- |
| 单个 `SHANIU.exe`（0.2.5 起的版本） | 直接放进固定文件夹，双击运行。第一次运行后旁边会自动出现 `data\`。 |
| 一个压缩包（群里只能发压缩包时） | 把压缩包**整个解压**，把解压出来的整个文件夹（里面有 `SHANIU.exe`、`portable.marker`、说明文件）放到固定位置，双击里面的 `SHANIU.exe`。 |

**压缩包形态要把整个文件夹一起用，不要只把 exe 单独拿出来。** `portable.marker` 的作用是把"数据放在 exe 旁边"这件事钉死：只要这个文件在，即使程序探测不出这个文件夹可写，也按便携处理，而不是悄悄把数据放到系统盘。

程序第一次启动时按这个顺序决定数据放哪（只判一次，之后记住）：

1. 有环境变量 `SHANIU_DATA_DIR`：用它（高级用法，普通用户不用管）；
2. 这个 exe 以前用过、有记录：用记录里的位置（把 exe 挪走也不会改判，见 1.1）；
3. 第一次启动，且 exe 旁边有 `portable.marker`，**或者已经有 `data\` 文件夹**：用旁边的 `data\`；
4. 以上都没有，但 exe 所在文件夹**能写**：在 exe 旁边建 `data\` 并使用（单文件 exe 走这条）；
5. 连写都写不进去（`C:\Program Files\`、只读介质）：改用系统盘的用户目录 `%LOCALAPPDATA%\SHANIU`。

所以第 3 条里"已经存在 `data\`"也算数——**你把一个已带 `data\` 的文件夹整体挪到新位置，程序认得它，数据会跟过去**；但只把一个 exe 复制到新文件夹，那不算，它会走第 4 条新建一个空 `data\`。

> 版本差异：**0.2.4 及更早的便携形态必须有 `portable.marker` 和 `SHANIU.exe` 放在同一个文件夹里**；少了这个文件，数据不会落在 exe 旁边，而是落到系统盘的用户目录 `%LOCALAPPDATA%`，看起来就像数据丢了。所以 0.2.4 及更早只能整个文件夹一起用，不能单拿 exe。0.2.5 起（含本版），exe 旁边可写就直接用旁边的 `data\`，单文件 exe 也能用。

### 1.3 运行前提

- Windows 10 或 Windows 11，64 位。其他系统不支持。
- 需要 Microsoft Edge WebView2 运行时。Windows 11 自带；较旧的 Windows 10 如果打不开，先装一次 WebView2（微软官网免费下载）。

### 1.4 第一次打开会看到什么

不会弹教程，也不会弹登录框。直接进入主界面：

- 中间是标题「探索未至之境」，旁边标着「预览版」。
- 下方是输入框，提示文字是「描述你想要构建的内容, / 调用指令, @ 文件或对话」。
- 右下角显示「请选择模型」——这说明还没有配置密钥。
- 左下角有一个齿轮图标，点开是「设置」。

### 1.5 怎么确认自己用的是哪个版本

程序里没有"关于"页面。看版本的办法：在 `SHANIU.exe` 上右键 → 属性 → 详细信息 → 看「文件版本」。或者看发给你时压缩包的文件名。

## 2. 配 API 密钥（最容易卡住的一步）

SHANIU 自己不提供模型，用的是你从服务商那里申请的 API 密钥。**没填密钥，程序能打开，但发消息一定是失败的。**

### 2.1 先申请一个密钥

本指南以内置的 DeepSeek 为例：

1. 用浏览器打开 DeepSeek 开放平台（`platform.deepseek.com`）。程序里没有跳转链接，需要自己打开。
2. 注册并登录，按平台的提示充值（新账号通常有少量赠送额度）。
3. 找到「API keys」页面，创建一个新的 key。
4. 复制这串 key。**key 只完整显示一次**，关掉页面后就看不到了，没存下来只能重新建一个。

key 看起来是 `sk-` 开头的一长串字母和数字，中间没有空格。它等同于你的账号余额，不要发到群里、不要截图外传。

> 设置页底部还有「添加模型提供商」，可以接入其他服务商。那些路径本指南没有逐一验证，填法类似，碰到问题按第 6 节处理。

### 2.2 填进去

两个入口都能到同一个页面：

- 点界面右下角的「请选择模型」；
- 或者点左下角齿轮「设置」，再点左栏的「模型」。

然后：

1. 在「模型」页找到 DeepSeek 这张卡片。没填过密钥时，卡片上是**红点**，写着「API 密钥缺失」。
2. 点卡片上的「编辑」。
3. 在「API 密钥」输入框里粘贴刚才复制的 key。输入框的灰色提示文字是「留空使用环境认证（DEEPSEEK_API_KEY）」，那是给高级用法准备的，普通用户直接粘贴 key 就行。页面上如果出现橙色警告「未检测到环境变量。请填写 API 密钥，或设置环境变量 DEEPSEEK_API_KEY。」，忽略它，填完 key 就不影响了。
4. 点「保存」。

保存成功后：

- 界面上出现一句提示「已保存 DeepSeek (deepseek)。」——它是**中性色**，只表示"写进了本机"，不表示"校验通过"。这两件事现在分开显示。
- 卡片上的红点变成**绿点**，文字变成「API 密钥已配置（未校验有效性）」。
- 卡片下方多出一块「API Key 校验」，保存后会自动跑一次，几秒内给出结论（见 2.4）。
- 右下角的「请选择模型」变成「选择模型，当前 DeepSeek-V4.1-Flash，推理等级 high」。

关掉程序再打开，绿点、校验结论和模型名还在，说明真的存下来了。

### 2.3 填错会看到什么（两种，都是实测原文）

**第一种：key 里带了空格或非法字符。**

- 输入框附近出现红字「该 API 密钥格式错误，请检查。」
- 「保存」按钮变成灰色，点不动。

这时候检查是不是复制时多带了空格或换行，重新粘贴即可。

**第二种：格式没问题，但 key 本身是错的（复制错、已被删除、或者余额不足）。**

- 保存会**成功**（格式合法），提示和绿点跟正确 key 一样。
- 但卡片下方的「API Key 校验」会给出结论：**红字「密钥无效」**，下面一行写原因，例如「端点明确拒绝了这把密钥（HTTP 401/403）」，右侧标着 `HTTP 401` 和耗时。
- 「API Key 校验」里有一行「原始响应」可以点开，能看到端点返回的原文，右边有「复制」按钮。
- 如果你没看校验结论直接发了消息：界面出现红点「本轮运行失败」和具体原因「API 密钥无效」，右侧标着失败码 `AUTH`。原因下面如果有「原始错误」一行，同样可以点开、复制。

### 2.4 保存后自动校验：三态怎么读

保存密钥后（以及每次更换密钥、改端点后），卡片下方的「API Key 校验」会自动发一次请求。它只问一件事：**这个端点认不认这把 key**。结论只有三种：

| 结论 | 含义 | 你要做什么 |
| --- | --- | --- |
| **密钥有效** | 端点接受了这把 key | 可以直接用 |
| **密钥无效** | 端点明确拒绝（HTTP 401/403） | 按 2.5 排查 key 本身 |
| **无法确认** | 判断不了：网络不通、超时、限流、服务端出错、端点没有模型列表接口 | 先按 2.5 排除网络，再点「重新校验」 |

「无法确认」**不等于**密钥无效。这一态故意不替你下结论，否则你会去改一把本来正确的 key。

校验不产生推理费用（只请求模型列表接口）。需要再试一次时，点校验区里的「重新校验」。

卡片上的绿点仍然只代表"已经存了一串格式合法的字符"，它的文字也写着「未校验有效性」——**有效性以校验结论为准，绿点不算数**。

端到端确认仍然只有一种方式：**在主界面发一句「你好」，能收到正常回复就是通了。**

### 2.5 校验说是「密钥无效」或「无法确认」，怎么排查

**结论是「密钥无效」时，按顺序查这四条：**

1. key 是不是复制全了（最前面是 `sk-`，中间没有空格换行）；
2. 这个 key 在服务商网站上是否还存在、是否被删；
3. 账号里还有没有余额；
4. 这个 key 有没有该模型的权限（有些 key 只开了部分模型）。

改完再点「保存」（或「重新校验」），看结论有没有变。

**结论是「无法确认」时，先看它写的原因：**

- 「连不上端点：网络不通或地址不对」「连接端点超时」：先确认能上网，在浏览器里打开 `platform.deepseek.com` 试试；用了代理的话，确认代理对程序生效。
- 「端点正在限流，稍后再试」：等一会儿再点「重新校验」。
- 「端点没有模型列表接口……」：这家服务商不支持这种校验方式，结论只能是「无法确认」，**不代表 key 错了**——直接发一句「你好」试。
- 「读取本机已保存的密钥失败」：密钥文件被占用或损坏，重启程序再试。

三种结论都改不动、发消息还是失败，就按第 6 节把材料发出来。

## 3. 日常使用

### 3.1 发消息

在主界面输入框里输入内容，然后发送。输入框里的 `/` 可以调指令，`@` 可以引用文件或对话。

### 3.2 关闭窗口不等于退出（重要）

点窗口右上角的 **X**，只是把窗口收进系统托盘，**程序还在后台运行**。任务栏右下角的托盘区能看到它的图标。

- 右键托盘图标，菜单里有三项：「显示」「后台运行说明」「退出」。
- 点「显示」把窗口调出来，点「退出」才是真正结束程序。
- **真正退出程序只能用托盘的「退出」。**
- 关窗时如果**有任务在跑**，或这是**本程序第一次**收进托盘，任务栏右下角会弹一条系统气泡（「SHANIU 仍在后台运行」/「SHANIU 已收进系统托盘」）。没弹也别慌：Windows 的通知设置或专注助手可能把它屏蔽了，以托盘图标为准。之后想再看这些说明，右键托盘图标 →「后台运行说明」。

这一点在更新版本时特别重要，见下一节。

## 4. 更新到新版本

### 4.1 先退出程序

点窗口的 X 只是隐藏，文件还被占用着，覆盖会失败。正确做法：**托盘图标右键 → 退出**，确认任务栏托盘里没有它了。

### 4.2 替换 exe，保留 data

1. 把新版本的 `SHANIU.exe` 复制到原来的固定文件夹。
2. 覆盖旧的 `SHANIU.exe`（系统会问是否替换，选是）。
3. **`data\` 文件夹不要动、不要删、不要覆盖。** 你的密钥、设置、会话都在里面。
4. 双击新的 exe，正常打开。

压缩包形态的更新方法一样：解压新压缩包，只把里面的 `SHANIU.exe`（和你手上形态需要的 `portable.marker`、说明文件）复制到原文件夹覆盖，`data\` 保持原样。

### 4.3 想换台电脑用

把整个文件夹（exe + `data\`）一起拷过去。注意：密钥是用 Windows 账户加密的，换一台电脑或换一个 Windows 账户后旧密钥解不开，程序会让你重新输入密钥。重新填一次就行。

---

## 5. 想彻底重来

如果配置乱了、想恢复到全新状态：先退出程序，把 `data\` 文件夹改名（比如改成 `data-旧`）或移到别处，再启动程序。程序会生成一套全新的空数据。

**不要直接删 `data\`**，除非你确定里面的会话和密钥都不要了——删掉之后没有回收站以外的恢复手段。

## 6. 出问题了怎么办

### 6.1 先自己看这三处

| 想看什么 | 在哪里看 |
| --- | --- |
| 密钥有没有配、校验结论是什么 | 「设置」→「模型」，DeepSeek 卡片是红点还是绿点；再往下看「API Key 校验」的结论（密钥有效 / 密钥无效 / 无法确认） |
| 当时的对话内容 | 在程序里打开那个会话，点右上角的「…」可以看到相关操作 |
| 程序自己的运行日志 | 固定文件夹下的 `data\logs\`，里面是按日期命名的文本文件 |

### 6.2 发到群里要带什么

按这个顺序，能给多少给多少：

1. **你做了什么、看到了什么。** 一句话就够，比如"填完 key 发你好，出现本轮运行失败，原因写 API 密钥无效"。
2. **截图。** 把出问题的整个窗口截下来，包括提示文字。截图前先把输入框和会话里的隐私内容清掉。
3. **会话 ID。** 打开出问题的那个会话，点右上角的「…」，选「复制会话 ID」，粘贴出来。
4. **会话日志。** 同一个「…」菜单里选「下载 Session 日志」，会弹出保存窗口（默认存到"文档"），得到一个 zip 文件，把它发出来。
   - 这个 zip 里装的是这次会话的对话记录。**它不包含你的密钥。**
5. **`data\logs\` 里当天的日志文件。** 直接把那一个文本文件拖进群里。

### 6.3 这些东西不要发出去

- **`data\secrets\` 整个文件夹**：里面是你的密钥文件。任何情况下都不用发。
- **API 密钥本身**：包括截图里露出的完整 key、粘贴的文本。发之前打码。
- **聊天记录里的隐私内容**：会话日志 zip 里是你和模型的全部对话，发之前自己过一遍。
- **`data\sessions\` 和 `data\rollouts\`**：这里面是所有会话的原始记录，只在需要时单独导出某一个会话，不要把整个文件夹打包发出来。

### 6.4 诊断包（0.3.0 才有，本版不可用）

现在还没有"一键导出诊断包"的功能。目前的替代做法就是 6.2 里的第 3–5 项，手动凑齐。

等 0.3.0 把这个功能做出来之后，会有一个按钮一次导出：程序版本、最近一段日志、脱敏后的配置。到那时这一节会改写。**在按钮真的出现在界面上之前，不要去找它。**

## 7. 常见问题速查

| 现象 | 多半是什么原因 | 怎么办 |
| --- | --- | --- |
| 双击没反应，或者一闪就没 | 多半是缺 WebView2 运行时 | 先装 WebView2 再试；仍不行按第 6 节发材料 |
| 界面能开，但右下角一直是「请选择模型」 | 还没填密钥 | 按第 2 节填 |
| 填了密钥，卡片还是红点 | 没点「保存」，或保存时被格式校验拦住了 | 看输入框下方有没有红字，改完再点「保存」 |
| 发消息出现「本轮运行失败」 | 提示那行会写具体原因（密钥无效 / 额度不足 / 限流 / 网络等），右侧是失败码 | 先按原因处理；要看端点原文就展开「原始错误」并复制；仍失败按第 6 节发材料 |
| 关掉窗口后，再双击 exe 打不开或提示占用 | 程序还在托盘里运行 | 托盘图标右键 →「退出」，再双击 |
| 换了文件夹或换了电脑，密钥、会话都没了 | 数据在原来的 `data\` 里，没跟着走 | 把原文件夹的 `data\` 一起拷过来 |
| 换了电脑后，原来看得见的密钥失效了 | 密钥和 Windows 账户绑定，换机解不开 | 重新填一次密钥 |
