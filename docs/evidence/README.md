# 证据库

> **规矩（长期有效）：证据必须入库，`scratch/` 只能放过程稿。**
> 凡是 `docs/**` 里写「见证据」「证据文件」「已核实」的地方，路径必须指向本目录下、在库里能直接打开的文件；
> 指向 `scratch/` 的一律视为**未落盘**，按「无法核实」处理。

## 为什么放这里

`scratch/` 被 `.gitignore:51` 忽略，里面的文件不进版本库：别人 clone 下来打不开，CI 也带不走，
等于没有证据。所以观测产物（JSONL、代码行摘录、复跑说明）一律归档到 `docs/evidence/<日期>/`。

## 归档约定

| 项 | 约定 |
| --- | --- |
| 目录 | `docs/evidence/<YYYY-MM-DD>/`，一个观测批次一个目录 |
| 必带文件 | `README.md`：这批证据是什么、什么时候产生、拿什么命令复跑、哪些结论「已核实」、哪些仍「无法核实」、缺什么才能补上 |
| 原始输出 | 保留机器原始格式（如 JSONL），**不要手工润色**；需要解释就写进 README |
| 来源标注 | 写明产生证据时的基准提交（如 `origin/main = 3b21b86`），否则行号会随代码漂移 |
| 禁止 | 不在证据里写「推测」「按理如此」；推测只能出现在文档正文，并明确标为「推断」 |
| 只读 | 采集证据的脚本不得修改被测系统（尤其是 DACL）；需要写入才能验的，登记为「待测」并写清测法 |
