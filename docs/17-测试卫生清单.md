# 测试卫生清单

> 记录「本机/并发环境下可复现、CI 上不出现」的测试噪音。**只记事实与规避方式，不许为它放宽判据**。

## 已知噪音

### 1. 同一 `CARGO_TARGET_DIR` 并发跑两份 `cargo test`

- **现象**：`tests/mcp_sandbox.rs::container_handshake_and_path_boundaries` 偶发失败，报
  `Cannot read package config \\?\<workspace>\package.json: operation not permitted`，
  MCP server 以 `exit=1` 退出。
- **取证**（2026-11-14）：并发跑的两份测试都会在同一个 `target\…` 下起沙箱容器、并对工作区
  目录做 ACL 预置/还原；两个进程的授权窗口互相覆盖，容器内的受限令牌读到的是对方还原后的
  中间态。单跑该用例必绿，CI 也从未出现（CI 每个 job 只跑一份测试）。
- **规避**：本机不要同时跑两份全量测试；需要并行时给第二份单独 `CARGO_TARGET_DIR`。
- **不做**：不改断言、不加 `#[ignore]`、不把错误吞掉。它指向的是真实的环境竞态，不是测试写错。
